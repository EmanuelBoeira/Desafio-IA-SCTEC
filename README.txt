autor: Emanuel Boeira Martins

Descrição:
    Este projeto foi realizado como desáfio da trilha de IA do programa SCTEC.
    Ele busca desenvolver um modelo de IA para predição do concelamento de diária
    em um hotel. Os dados publicos foram disponibilizados pale platafoma Kaggle
    em formato CSV.
    O projeto foi executado em python.
    O arquivo data-analysis.py foi utilizado para uma analise inicial dos dados. O
    modelo de predição foi desenvolvido no arquivo predict-model.py. O modelo utilizado
    foi o LogisticRegression e as métricas utilizadas foram Accuracy e AUC-ROC.

Dependências:
    pandas
    seaborn
    matplotlib
    numpy
    scikit-learn

Forma de execução:
    Os arquivos devem der executados pelo terminal como no exemplo a seguir:
    python predict-model.py
